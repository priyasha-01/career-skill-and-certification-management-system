Local vs Real Cloud Deployment Architecture

Coursework mapping guide for viva defense and project explanation.

This mini-project is designed to run locally for development and evaluation using an in-memory SQLite database and FastAPI async web server. In a production cloud environment (e.g. AWS or GCP), each layer seamlessly maps to managed cloud infrastructure services.

Frontend Layer

Single Page UI

Local: Static HTML/JS

☁️ AWS S3 + CloudFront CDN

Global edge caching & instant static asset delivery.

Backend API Layer

FastAPI REST Server

Local: Uvicorn ASGI (:8000)

☁️ AWS EC2 / GCP Cloud Run

Auto-scaling container workloads running Uvicorn workers.

Database Layer

SQLAlchemy ORM

Local: SQLite :memory:

☁️ AWS RDS (PostgreSQL)

Managed relational database with auto-backups & multi-AZ failover.

API Documentation

Swagger OpenAPI

Local: /docs endpoint

☁️ AWS API Gateway

Rate limiting, endpoint throttling & swagger validation.

Architecture Breakdown & Component Mapping

Component Local Implementation Cloud Equivalent (AWS/GCP) Key Advantage
Backend Web Server FastAPI (Python async) AWS EC2 / GCP Cloud Run Asynchronous I/O handling thousands of requests per second
Database Engine SQLite In-Memory (:memory:) AWS RDS PostgreSQL Zero configuration for local demo; instant persistent scaling in cloud
Frontend Hosting Static Single-Page HTML/JS AWS S3 + CloudFront CDN Low-cost distribution with low latency worldwide
Certificate Generation Dynamic Unique Hash Generator AWS Lambda + S3 Signed URLs Immutable credential verification code generated on completion
